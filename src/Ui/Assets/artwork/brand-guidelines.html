Clear space & minimum size

Keep clear space ≥ X on all sides, where X = the cap-height of the wordmark.

Minimum size

Full lockup: 24 px tall on screen / 8 mm in print.
Symbol alone: 16 px. Below ~24 px the inner arcs simplify out — use favicon.svg (bold c + dot) for tiny sizes.

PNG/ICO exports are provided at every required size: favicon 16/32/48 + .ico, apple-touch 180, PWA 192/512, and a maskable 512 with safe-zone padding. A site.webmanifest and paste-ready <head> tags are in /web.

Type

circuitRF
Wordmark: Inter — “circuit” SemiBold (600), “RF” Bold (700), tracking −3. In production SVGs the type is converted to outlines, so the font is not required to render. Use Inter (or the system sans stack) for surrounding UI/marketing copy.

Usage

Do — give it room; use reversed on dark; size by height; recolor to a single brand color when needed. Don't — stretch or rotate it; enlarge the coral dot; recolor the mark to off-brand hues; place the color mark on low-contrast or busy backgrounds.
