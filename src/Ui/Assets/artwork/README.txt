circuitRF — brand kit (concept 01a: Ink + Cyan / Coral)
=========================================================
Wordmark face: Inter (SemiBold "circuit", Bold "RF"). All SVGs in /logo, /icon,
/web (except *-editable) have the type CONVERTED TO OUTLINES — no font required.
