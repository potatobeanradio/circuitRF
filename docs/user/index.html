What is circuitRF?

circuitRF studies the frequency response and nonlinear behavior of RF circuits — from a handful of components to hierarchical, multi-port designs. It is an RF simulator, not a SPICE simulator: the analyses and workflow are built around the RF/microwave problem, the file formats are human-readable, and loadpull is a first-class experiment. Simulation results are stored as NumPy .npy datasets, so they drop straight into Python/MATLAB workflows.
