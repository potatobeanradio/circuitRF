What is circuitRF?

circuitRF studies the frequency response and nonlinear behaviour of RF circuits — from a handful of components to hierarchical, multi-port designs. It is an RF simulator, not a SPICE simulator: the analyses and the workflow are built around the RF/microwave problem, the file formats are human-readable, and loadpull is a first-class experiment. Results are stored as NumPy .npy datasets, so they drop straight into Python or MATLAB.

Alongside the circuit engines it carries a planar method-of-moments EM solver for layout, a 3D bondwire kernel, and harmonicaRF — an interactive harmonic load-pull bench for a single device.
