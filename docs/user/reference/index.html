circuitRF Reference Guide

The complete technical reference — every simulation and its parameters, every library component, the plot types, the netlist format, and the symbol conventions. Plain and direct; look things up here.

Chapters

1 · Simulations

simulations.html — one section per analysis (DC, S-parameters, Harmonic Balance, Loadpull/Pursuit, Parametric Sweep). Each covers what it computes, a brief algorithm overview with key equations (referencing the white papers rather than deriving), and every setting — max harmonic order, tolerances, continuation, grid definition, and so on.

2 · Components

components.html — one section per library component, each with its symbol rendering and a full parameter table. Written to grow as the library grows.

2a · The SDD (Symbolically-Defined Device)

sdd.html — circuitRF's user-authored nonlinear device, in depth: the equation grammar (I[p,w], Q[p]), weighting functions H[w], and how to reference another device's current (control currents _cn / C[n]) — with worked current-mirror and feedback examples.

3 · Pins, Ports & Terms

pins-ports-terms.html — the definitive treatment of the three concepts, with rendered symbol diagrams, and why distinguishing them matters.

4 · Dynamic symbols (SDD, ZPort, SnP)

dynamic-symbols.html — components whose symbol grows with port count, including the SnP pin arrangement, pitch, and floating reference pin options.

5 · The Nonlinear Capacitor & the C–V Editor

nonlinear-capacitor.html — the polynomial (Taylor-series) C(V) model, how the C–V Editor generates the coefficients, and the Apply step that commits them.

6 · Plot types

plot-types.html — Rectangular, Smith, Polar, and Table, step by step. Notably: Table shows complex and scalar data together, while Rectangular is scalar-only and Smith/Polar are complex-only.

7 · The netlist (.cnl) format

netlist.html — what a circuitRF netlist is, what it's for, and a fully annotated example explaining each line.

8 · Expressions

expressions.html — the one expression language used everywhere (variables, parameters, SDD equations, measurements): values, operators, functions, units, scope, user-defined functions, and cycle detection.

9 · Measurements

measurements.html — named figures of merit computed from results, the two cube-reference notations (accessor vs. bracket), S-parameter port indexing, composition, and swept variables.

10 · Grid & Connectivity

grid.html — the two-grid model (coarse connection grid, fine authoring grid), why connection is exact equality, and how cross-grid paste is handled.

11 · File formats

file-formats.html — schematic vs. netlist, the full .csch / .csym / .ccell / .cdd / .cws family, and how Workspace › Library › Cell map to folders.

12 · Symbol Editor

symbol-editor.html — authoring a cell's glyph: drawing primitives, pins and port mapping, the two snap grids, orientation conventions, locked symbols, and the auto-generator.

13 · Results & Data Export

npy-export.html — where a run's results live, the DataSet/DataCube model, exporting to .npy / .mat / TSV / Touchstone / loadpull formats, grouped results, and a Python quick-start for reading the .npy.
