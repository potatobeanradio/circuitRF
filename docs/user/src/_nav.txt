# The reading order of the circuitRF User Documentation.
#
# ONE order, top to bottom. It drives three things at once and they cannot
# disagree with each other, because all three are derived from this file:
#
#   * the complete table of contents on index.html   ({{toc: site}})
#   * the Previous / Next chain at the foot of every page
#   * the orphan check — a generated page that is not listed here fails the
#     run by name, and a page listed here that nothing produces does too
#
# index.html is the head of the chain implicitly. Do not list it: it IS the
# table of contents.
#
# Format:   <slug relative to docs/user>  |  one-line blurb for the contents
# Sections: == Section title
# ---------------------------------------------------------------------------
