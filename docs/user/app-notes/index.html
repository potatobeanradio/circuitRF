circuitRF Application Notes

Worked investigations of questions that come up in real designs, with the measurements behind the answers.

The Reference Guide says what every control does. An application note answers a question that only shows up once you are using them together on a real board — usually a question of the form "the tool told me two things and I do not see how both can be true."

Each note is a complete investigation rather than a summary: the structure, what was measured, what the numbers turned out to mean, and what to do differently. Where a note quotes a number, that number came out of a run, and the note says which run.

Reading these

Every note is self-contained, so they can be read in any order and none of them is a prerequisite for another. They do assume the relevant Reference chapter — a note about EM ports will link to the MoM engine rather than re-explain de-embedding.
