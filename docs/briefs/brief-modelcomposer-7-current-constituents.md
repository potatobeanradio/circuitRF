## 1. Goal

`Id` and `Ig` as functions of the intrinsic voltages, built by whichever method the user picks, from DC or pulsed
I–V — with the extrapolation domain, the symmetry jump and the fit quality reported.

## 2. Requirements

**R-mc7-1 — Training data.**
- The intrinsic points of the chosen I–V data sets (MC-4 R-mc4-4), with excluded points removed.
- One temperature per fit until MC-9; pulsed sets from one quiescent point until MC-10. A mix that later phases
  handle is refused here, naming the condition that differs.
- `Id` is the channel current. `IgGs`/`IgGd` are split from the measured gate current: by default all of it is
  `IgGs` for `Vds ≥ 0` (forward) and the reverse part goes to `IgGd` (breakdown), by the sign rule documented in the
  design note; the user can choose a split.

**R-mc7-2 — Methods.**
- **ANN** (default): MC-6 value training on the scattered intrinsic points. `Id` is weighted so that sub-threshold
  and saturation both matter — relative weighting with a floor, a setting. `Ig` uses log-magnitude weighting.
- **Table**: re-grid the scattered intrinsic points onto a rectilinear intrinsic grid, then MC-2's spline.
  Re-gridding, in order of preference:
  1. through a trained ANN;
  2. through the existing `Rbf2D` (`src/RfCore/Loadpull/`).

  Grid spacing is a setting. A warning when the spacing exceeds the smallest expected signal swing is computed
  from it ([P1] Fig. 6.8): "table step 0.2 V: low-level IM below ~0.1 V swing unreliable".
- **Equation**: a template or the user's own expression, with named parameters fitted by the existing optimizer
  algorithms (least squares on the same weighted residual).
  - Templates are the `Id` forms of circuitRF's built-in FET families (`AngelovFetModel`, `CurticeQuadratic`,
    `CurticeCubic`, `Statz`, `Materka`), written as expressions, plus a diode `Ig`.
  - The templates are copies of the expressions, not calls into those classes, so a fitted model is
    self-contained.

**R-mc7-3 — Domain and symmetry.**
- The training domain's hull (MC-3 coverage, in intrinsic coordinates) is written as the constituent's
  `Extrapolation` domain, and `G_x` is set (MC-2 R-mc2-3).
- With `Symmetry: Exchange` the fit uses `vds ≥ 0` points only and reports the value and slope jump at
  `vds = 0`.

**R-mc7-4 — DC/RF dispersion (optional; off by default).** [P1] eq. 6.52 as an internal state node `x`:
- `Id = IdRF(v) + x`, with `τ dx/dt + x = IdDC(v) − IdRF(v)`.
- At DC, `Id = IdDC`; at frequencies far above 1/τ, the small-signal current follows `IdRF`.
- `IdRF` is trained by **MC-6 derivative training** on the intrinsic `Gm` and `Gds` from the S data ([P1] §6.4.2),
  anchored to `IdDC` at a reference bias. `τ` is a setting, default 1 µs ([X06]: "typically on the order of
  1 µs"). This is [X06]'s five-function model (`IdDC`, `IgDC`, `IdRF`, `Qg`, `Qd`).
- Implemented through MC-1's internal-node seam (`q = τ·x`, `i = x − (IdDC − IdRF)`).
- The step reports [P1] eq. 6.49's residual as the dispersion's own consistency check.
- The window describes this option as the simpler alternative to modelling heating and traps (MC-9, MC-10), which
  [P1] prefers.

**R-mc7-5 — Fit report.**
- Training and held-out RMS error, absolute and as % of the range.
- `Gm`/`Gds` from the fitted function against the DC derivatives of the data (a measure of noise in the data).
- The domain hull.
- All results go to the `.cmc` `Steps.Current` block. Training runs through `RunControl` (D13).

## 3. Not in this phase
Temperature as an input (MC-9); trap states (MC-10); charges (MC-8). A transconductance-delay element is in no
phase: the charges carry it as `Cm` (D4).

## 4. Gates (minimal tests, run only these classes)
- `CurrentFitAnnTests` — on `SyntheticFetData` (one temperature, one quiescent point), the ANN `Id` reproduces the
  SDD truth's channel current at held-out intrinsic points within a stated tolerance; `Ig` within a stated
  log-domain tolerance.
- `CurrentFitTableTests` — the table path's re-gridded spline reproduces the truth within tolerance; the
  grid-step warning fires for a coarse grid and not for a fine one.
- `CurrentFitEquationTests` — fitting the Angelov template to data generated by an Angelov `Id` recovers its
  parameters within tolerance.
- `DispersionNodeTests` — a model with `IdDC ≠ IdRF` gives `IdDC` in a DC solve and `IdRF`'s conductances in an
  S-parameter run at f ≫ 1/τ (to 1e-6), and HB is continuous across the corner frequency.
